# Бесплатный запуск бота без карты и без ПК 24/7

**Проект:** `D:\projects\COFEPOINT` · бот `@coffeefriends_orders_bot`  
**Режим:** long polling (`npm start` в `tg/`).

## Честно про ограничения

| Вариант | Бесплатно | Без карты | 24/7 | Без переписывания бота |
|---------|-----------|-----------|------|------------------------|
| Oracle / AWS / Fly / Railway | частично | ❌ обычно нужна карта | ✅ | ✅ |
| **GitHub Pages / Actions** | ✅ | ✅ | ❌ | — |
| **Старый Android + Termux** | ✅ | ✅ | ✅* | ✅ |
| Cloudflare Workers (webhook) | ✅ | ✅ | ✅ | ❌ нужен другой код |
| Render free | ✅ | иногда | ❌ засыпает | ✅ |

\* Пока телефон включён, на зарядке и в Wi‑Fi.

**Вывод:** при «бесплатно + без карты + нет ПК» самый быстрый путь — **запасной телефон как мини‑сервер**. Облако без карты для Node long polling по сути только через **webhook** (доработка бота) или ненадёжные «костыли».

## Рекомендация: Android + Termux

Подходит, если есть **любой старый Android** (можно без SIM, только Wi‑Fi).

Пошагово: **[termux-android.md](./termux-android.md)**

Кратко:

1. Termux с [F-Droid](https://f-droid.org/packages/com.termux/) (не из Google Play — там старая версия).
2. `pkg install nodejs git` → клонировать репозиторий или скопировать `tg/` + `assets/data/menu.json`.
3. `token/token.txt`, `config.json`, `.env` — как в `tg/README.txt`.
4. `npm install && npm start` — проверка в Telegram.
5. **Termux:Boot** — автозапуск после перезагрузки телефона.
6. Телефон: зарядка + Wi‑Fi, экран можно гасить (отключите оптимизацию батареи для Termux).

## GitHub — только для кода, не для бота

- **GitHub Pages** — сайт CoffeeFriends (уже так).
- **GitHub Actions** — не держит бота 24/7 (лимит минут, задачи не вечные).
- **GitHub + Railway/Fly** — деплой удобен, но Railway/Fly **просят карту** → вам не подходит.

---

## Если позже появится карта или ~200 ₽/мес

- VPS в РФ (Timeweb, Selectel) — стабильнее телефона, инструкция как для Oracle: `oracle-cloud-ubuntu.md` (те же шаги systemd).

## Облако без карты (нужна доработка бота)

**Cloudflare Workers** (бесплатный тариф, карта обычно не нужна):

- Telegram шлёт updates на **webhook** (HTTPS).
- Текущий бот на **long polling** — придётся переписать на webhook + хранение состояния (KV/D1).
- Имеет смысл, если телефон не вариант; отдельная задача в разработке.

---

## Чего не делать

- Два `npm start` с одним токеном (ПК + телефон) — заказы ломаются.
- Render free «как есть» — сервис засыпает, заказы пропадают.
- Хранить `token.txt` в публичном GitHub.
