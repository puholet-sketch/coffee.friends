# Где бесплатно (или почти) крутить бота 24/7

Сайт на GitHub Pages — только страница. **Бот** — отдельная программа, она должна **постоянно работать** на сервере или на вашем ПК.

## Вариант 1. Ваш компьютер (0 ₽, проще всего)

1. Установите Node.js 18+.
2. Положите токен в `tg/token/token.txt`.
3. В папке `tg`: `npm install`, затем `npm start`.
4. Окно терминала **не закрывать**. Если Telegram блокируют — включите VPN на ПК.

Минус: пока ПК выключен или спит — бот не отвечает.

---

## Вариант 2. Oracle Cloud «Always Free» (0 ₽, 24/7)

Бесплатная маленькая виртуалка в интернете (не выключается за неактивность, в отличие от Render).

Кратко:

1. Зарегистрируйтесь на https://cloud.oracle.com (нужна карта для верификации, списаний не будет при free tier).
2. Создайте VM (Ubuntu), откройте SSH.
3. Установите Node.js, склонируйте репозиторий (или скопируйте папку `tg` + `assets/data/menu.json`).
4. Создайте `tg/token/token.txt` на сервере (токен **не** в git).
5. Запустите бота через **pm2**: `npm install -g pm2`, `cd tg && npm install`, `pm2 start bot/index.mjs --name coffeefriends`, `pm2 save`, `pm2 startup`.

В России до api.telegram.org может понадобиться VPN/прокси на сервере — уточняйте по факту.

## Вариант 3. Render / Railway / Fly.io (условно бесплатно)

Есть бесплатные тарифы, но часто:

- сервис **«засыпает»** без трафика;
- для Telegram-бота с опросом (polling) это **плохо** — заказы не приходят, пока сервис спит.

Имеет смысл только с **платным** «always on» или если перевести бота на **webhook** (отдельная доработка).

---

## Что положить на сервер

Минимум:

- `tg/bot/` — код бота
- `tg/package.json`, `package-lock.json`
- `tg/config.json`
- `assets/data/menu.json`
- `tg/token/token.txt` — только на сервере, вручную

Команда запуска: `cd tg && node bot/index.mjs`
